# Single Layer Perceptron for Binary Classification

## Deep Learning Laboratory - Experiment 1

Implementation of a Single Layer Perceptron from scratch for binary classification using the **Banknote Authentication Dataset**.

## Tasks Covered
- Dataset exploration and EDA
- Data preprocessing and normalization
- Perceptron implementation from scratch
- Model training using perceptron learning rule
- Performance evaluation using accuracy, precision, recall, F1-score, and confusion matrix
- Learning rate analysis
- Comparison with Scikit-learn Perceptron

## Dataset
**Banknote Authentication Dataset (UCI Repository)**  
Features:
- Variance
- Skewness
- Curtosis
- Entropy

Target:
- 0 : Authentic Banknote
- 1 : Forged Banknote

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Results
The implemented perceptron successfully classifies banknotes with high accuracy and demonstrates the learning behaviour through different visualizations.
